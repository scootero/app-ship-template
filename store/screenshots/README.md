- **Commit or not?** Screenshots are big. Committing them gives history; ignoring them keeps the repo small. Blip keeps its large raw captures out of the website build. Default here: committed. To stop, add `store/screenshots/*/` to `.gitignore`.
- **Upload:** App Store Connect → your app → the version → drag the PNGs into each device slot. Automating the upload is a later step (README → "Later").
- **Order matters:** the first 3 screenshots show in search results. The `NN-` prefix controls order and comes from `SCREENSHOT_ROUTES` in `ship.config`.
